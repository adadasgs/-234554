# Telegram NFT Offers Bot

Бот для создания красивых офферов на NFT-подарки в Telegram.

## Возможности

- Создание оффера командой вида: `SnoopCigar-84846 3200 stars`
- Красивое оформление сообщения
- Кнопки **Принять** / **Отклонить**
- После принятия — кнопка передачи подарка менеджеру (`tg://send_gift?to=Autooffersgift`)
- После подтверждения передачи — сообщение об ожидании проверки (30 минут)

## Установка

1. Клонируй репозиторий
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создай файл `.env` и вставь токен бота:
   ```
   BOT_TOKEN=123456:ABC-DEF...
   ```
4. Запусти:
   ```bash
   python bot.py
   ```

## Как пользоваться

В любом чате (или бизнес-чате) напиши:

```
SnoopCigar-84846 3200 stars
```

Бот сразу отправит красивый оффер.

## Настройки

В файле `bot.py` можно изменить:

- `MANAGER_USERNAME` и `MANAGER_LINK`
- Курс `STARS_TO_USD`
